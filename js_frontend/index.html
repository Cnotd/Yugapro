关于系统

系统架构

本系统采用前后端分离架构：

  • 后端：Rust + Axum 高性能Web框架
  • 前端：原生JavaScript + CSS
  • 数据库：SQLite 轻量级数据库
  • AI模型：Qwen3-4B 本地大语言模型

技术特点

  • 高性能：Rust后端提供卓越的处理速度
  • 安全可靠：本地化部署，数据不外传
  • 易于扩展：模块化设计，便于功能扩展
  • 跨平台：支持Windows、macOS、Linux
