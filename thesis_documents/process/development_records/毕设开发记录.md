## 一、项目概述

### 1.1 项目名称
**瑜伽动作智能评估系统** (Yoga Pose Assessment System)

### 1.2 项目目标
基于人工智能技术，开发一个能够对用户上传的瑜伽动作视频进行智能评估的系统，提供专业的动作分析、评分和改进建议。

### 1.3 技术选型

| 组件 | 技术栈 | 说明 |
|------|--------|------|
| 后端框架 | Rust + Axum / Python + Gradio | 双版本实现 |
| 前端 | HTML + CSS + JavaScript | 前后端分离 |
| 数据库 | SQLite | 轻量级本地存储 |
| AI模型 | Qwen3-4B / Ollama | 本地大语言模型 |
| 姿态检测 | MediaPipe | Google姿态检测 |

#### 第四阶段：运行调试（2026-04-02）

**用户反馈**：不能正常运行

**问题诊断**：
1. AppState在lib.rs和main.rs中定义不一致
   - lib.rs: `Arc<PoseAnalyzer>`
   - main.rs: 直接类型

2. health.rs端点在调用数据库时可能崩溃

**解决方案**：
1. 统一AppState定义
```rust
#[derive(Clone)]
pub struct AppState {
    pub db: Database,
    pub pose_analyzer: PoseAnalyzer,
}
```

2. 简化health.rs
```rust
pub async fn health_check() -> Json<serde_json::Value> {
    Json(serde_json::json!({
        "status": "ok",
        "version": "0.1.0",
        "service": "yoga-assessment-api",
    }))
}
```

## 四、核心功能模块

### 4.1 Rust后端 API

```rust
// 主程序入口
#[tokio::main]
async fn main() -> Result<()> {
    // 初始化数据库
    let db = Database::new("data/yoga_assessment.db").await?;
    
    // 初始化姿态分析器
    let pose_analyzer = PoseAnalyzer::new()?;
    
    // 创建应用状态
    let state = AppState { db, pose_analyzer };
    
    // 构建路由
    let app = Router::new()
        .route("/api/health", axum::routing::get(health::health_check))
        .route("/api/assessment/upload", axum::routing::post(assessment::upload_video))
        // ... 其他路由
        .layer(cors)
        .with_state(state);
    
    // 启动服务器
    axum::serve(listener, app).await?;
}
```

class YogaAPI {
    constructor(baseUrl = 'http://localhost:8080/api') {
        this.baseUrl = baseUrl;
    }
    
    async uploadVideo(file, poseName = '下犬式') {
        const formData = new FormData();
        formData.append('video', file);
        formData.append('pose_name', poseName);
        
        const response = await fetch(`${this.baseUrl}/assessment/upload`, {
            method: 'POST',

        });

## 五、遇到的问题及解决方案

### 5.1 OpenCV依赖问题

**问题**：opencv = "0.87" 版本不存在

**原因**：crates.io上最新版本是0.98.x

**解决**：
1. 尝试升级到0.98版本
2. 发现需要libclang库，Windows配置复杂
3. 决定移除opencv，改用Python脚本调用

### 5.2 Rust编译错误

**问题列表**：
1. 类型推断不明确
2. 导入路径错误
3. Clone trait缺失
4. Router配置问题

**解决方案**：
- 显式指定返回类型
- 统一使用`crate::`导入
- 为所有状态结构体添加Clone
- 使用正确的axum 0.7 API

### 5.3 AppState不一致

**问题**：lib.rs和main.rs中AppState定义不同

**解决**：
```rust
// lib.rs
#[derive(Clone)]
pub struct AppState {
    pub db: Database,
    pub pose_analyzer: PoseAnalyzer,
}
```

### 5.4 CORS跨域问题

**问题**：前端无法调用后端API

**解决**：
```rust
let cors = CorsLayer::new()
    .allow_origin(Any)
    .allow_methods(Any)
    .allow_headers(Any);
```
